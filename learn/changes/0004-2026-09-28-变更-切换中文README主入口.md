# 切换中文 README 主入口

日期：2026-09-28

## 背景

仓库主入口 `README.md` 原为英文，中文内容只在语言切换栏中作为次要入口。
独立维护后，需要让中文成为主入口。

## 执行

1. 新增 `resource/README.en.md`：原英文 README 全文迁移，内容不变，
   仅按新位置修正相对路径。
2. 重写根目录 `README.md` 为中文版，结构与原英文版一一对应
   （项目简介 / 核心模块 / 架构 / 快速开始 / 界面截图 / 技术栈 / 致谢 /
   来源说明 / 许可证）。术语沿用 `resource/USAGE.zh-CN.md` 的既有风格：
   Skill、Sandbox、MCP、TUI、middleware、provider 等技术词保留英文，
   叙述用中文，避免同一概念出现两套译名。
3. 打通语言切换栏：根 `README.md` → `resource/README.en.md`、
   `resource/USAGE.zh-CN.md`、`resource/USAGE.ja.md`；
   三份 USAGE 增加回指根 `README.md` 的链接。

## 一并修正

- `resource/README.en.md` 内的相对路径：迁移后 `LICENSE`、`USAGE.md`、
  `learn/`、图片 `resource/assets/` 全部需上跳一级，已逐项修正。
- `README.md` 快速开始的克隆地址原为占位符 `<repo-url>`，替换为
  `https://github.com/xilele777/poirot.git`。

## 核对

- 五份文档（根 `README.md`、`resource/README.en.md`、`USAGE.md`、
  `resource/USAGE.zh-CN.md`、`resource/USAGE.ja.md`）的相对链接全部可达，
  失效数 0。
- `README.md` 与 `resource/README.en.md` 引用的 4 张图片路径均存在。
- 快速开始步骤与实际配置一致：`pip install -e ".[dev]"`、
  `cp .env.example .env`、`poirot`。
- 未改动任何代码或测试，无需运行测试套件。
