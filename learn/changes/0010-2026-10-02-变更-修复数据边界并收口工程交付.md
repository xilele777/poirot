## 改动与结果

### 产物与路径

- 新增统一路径组件校验：拒绝 `..`、反斜杠、驱动器/ADS、空组件和 Windows 保留名称，宿主目标解析后验证根目录归属。
- Docker 反向翻译验证源路径归属；Local 增加仅接受已配置映射的导出接口。符号链接越界由解析后的归属检查拒绝。
- SandboxMiddleware 的输出目录由应用注入，删除反向导入 app.bootstrap；翻译失败不再拼接备用路径，复制失败或文件缺失不再注册成功下载。
- Docker guard 识别带引号的直接绝对路径重定向；仍不宣称解析全部 shell 写入语义。

### 记忆一致性

- 稳定 sidecar 跨进程锁覆盖读改写，在锁内重读最新文件；完整序列化、flush/fsync 后原子替换，失败不破坏旧文件并恢复缓存。
- 读取刷新独立实例变化，检索前校准索引；检索强化用 compare-and-update 防止恢复其他实例修改/删除的旧记录。
- 修复提交后 YAML 规范化造成缓存与落盘表示不同的问题；扩展 trace ID 解析，合法非十六进制 ID 不再重启丢失。
- 多进程回归暴露 Windows 空锁文件初始化竞争；改为直接锁定文件区域，不在取锁前写初始化字节。带启动屏障的一致性回归连续运行 5 次通过。

### 装配与能力

- `_assemble_leader` 统一启动、leaf、模式切换、模型切换和 MCP 重载的依赖注入，减少重复参数遗漏。
- 增加 agents 禁止反向 import app 的架构测试。
- 专家 L2/L3 缺少真实应用依赖时在启动前报错，尚未建日志/指标库就终止；普通委派仍保留。低层实验组件及其单测保留，未冒充完成自动进化。
- Skill evaluator 改用公开 setter 注入。版本发布或评估记录失败向上传播；失败/拒绝的 capture 不再写成功 capture 事件。创建版本与写记录仍不是同一事务，已记录限制。

### 发布与文档

- wheel 显式打包 prompt、Skill、YAML、TS，排除测试包。
- `scripts/check_wheel.py` 在干净临时源码构建，逐个核对运行资源、独立目录安装并使用 `python -I` 验证资源加载及构图。
- 添加 Windows/Python 3.12 的 GitHub Actions 默认测试和安装包门禁。未推送，本地不能声称远端 CI 已通过。
- 重写中英文 README，修正保留的使用参考及配置样例中的自动进化声明；新增 docs 能力限制、开发验证、架构边界说明；learn 导航改为简短分类入口。

## 已知限制和下一步

真实 LLM、Docker、外部专家 CLI 与研究效果未进行本轮端到端验收。Local 不是安全容器；宿主恶意进程并发替换路径不在文件归属检查的完整防护范围内。Markdown 仍全量重写，不是跨多个 manager 操作的事务；同 trace 显式替换需由调用者自行选择条件更新。

自动 Skill 调度/回滚、真实专家进化评估、中文召回、持久化会话恢复、大函数拆分与全面类型门禁列入[后续计划](../plans/0004-2026-10-02-计划-自动化能力与真实环境验收.md)。本轮不推送、不发布，不修改先前未提交的其他评审或工具目录。
