# 修复测试套件与沙箱并发缺陷

日期：2026-09-28

## 背景

克隆仓库后首次运行完整测试，出现 21 个失败。排查发现其中既有环境缺失，
也有真实的代码缺陷与测试间污染。本记录汇总根因与修复，供后续复核。

## 根因与修复

### 一、真实代码缺陷

1. **`acquire_async` cancel 后锁永久泄漏**（`sandbox/docker/docker_sandbox_provider.py`）
   - 原实现 `await asyncio.to_thread(thread_lock.acquire)`。`threading.Lock.acquire`
     是阻塞调用，`asyncio.to_thread` 只让协程侧可被 cancel，底层线程仍在等待；
     一旦锁被释放，该孤儿线程会抢到锁且无人 release。
   - 后果：该 `thread_id` 之后所有 `acquire` 死锁。
   - 修复：改为 `thread_lock.acquire(blocking=False)` + `asyncio.sleep` 轮询，
     把等待切成可取消的 await。
   - 最小复现脚本确认了泄漏行为；同时加固了
     `test_cancel_before_acquire_no_release_error`，使其在旧实现上确定性失败。

2. **上下文压缩 prompt 丢失对话历史占位符**
   （`prompts/system/context_engineering/default/summarize.md`）
   - 英文化提交 `5b6043f` 重写模板时，把末尾的 `${messages_text}` 一并删掉，
     只留了标题 `## Conversation to Compress`。
   - 后果：`SummarizerExecutor._call_llm` 传入的对话历史被静默丢弃，
     L4 上下文压缩实际失效。`PromptManager._render` 只在"模板有占位符但未传值"
     时告警，反向情况无提示，因此未被发现。
   - 修复：补回 `${messages_text}`。

3. **沙箱镜像名错误**
   （`config/loader.py`、`sandbox/docker/*.py`、`.env.example`、三份 `USAGE`）
   - 默认值与文档均为 `all-in-one-sandbox:latest`，但该镜像在 Docker Hub /
     GHCR 均不存在，`docker pull` 直接失败。
   - 实测正确的镜像为 `ghcr.io/agent-infra/sandbox:latest`（agent-infra 官方
     的 AIO sandbox，暴露 8080/tcp，`/v1/sandbox` 返回 HTTP 200）。
   - 修复：代码默认值与全部文档统一改为正确镜像名。

### 二、测试间污染（导致"单独跑通过、全量跑失败"）

4. **`PATH` 全局污染**（`tests/v1/unit/mcp/test_guards_selfcheck.py`）
   - 直接赋值 `os.environ["PATH"] = "/usr/bin"` 且不还原。
   - 后果：其后所有依赖 `shutil.which` 的测试连锁失败，共 5 个
     （4 个 pi_installer + 1 个 stage3 truncation）。
   - 修复：改用 `monkeypatch.setenv`，自动还原。

5. **`sys.modules["agent_sandbox"]` 全局污染**
   （`tests/v1/unit/sandbox/test_docker_runtime.py`、
   `test_docker_sandbox_provider.py`）
   - 模块导入时注入假 `agent_sandbox`（`Sandbox = MagicMock`）且不还原。
   - 后果：先导入这两个文件后，stage5/6 集成测试拿到假 SDK，端到端断言失败。
   - 修复：仅在真实包缺失时注入占位模块；SDK 客户端改为按用例
     `monkeypatch.setattr(docker_runtime, "AioSandboxClient", ...)`，自动还原。

6. **测试未隔离宿主环境变量**
   - `test_claude_credential.py`：provider 会回退读 `ANTHROPIC_AUTH_TOKEN`，
     但用例只清了 `CLAUDE_CODE_OAUTH_TOKEN`，开发机设有该变量时失败。
     修复：加 autouse fixture 清空全部相关变量。
   - `test_pi_installer.py`：`_install_in_background` 系列只 mock 了
     `subprocess.run`，让 `shutil.which("npm")` 依赖宿主 PATH。
     修复：加 autouse fixture 默认 mock npm 可用。
   - `test_local_container_backend.py::test_no_name_none`：依赖"宿主无 docker"
     才通过。修复：改为 mock `subprocess.run`，确定性断言。

### 三、测试与代码漂移（代码为权威，更新测试）

7. `test_config_loader.py`：断言 `max_loop_steps == 8`，代码 EXPERT_PROFILE 已为 100。
8. `test_merge_sandbox.py`：断言 state 键 12 个，记忆系统已新增
   `recalled_memories` / `memory_updates` 两个字段。
9. `test_default_strategy.py`：断言模板含中文"对话历史"，模板已英文化；
   且该断言连带暴露了上面的缺陷 2。
10. `test_stage5_integration.py`：用 `itest01` 这类 id，与 S6 新增的
    `^[a-f0-9]{8}$` 校验冲突。

## 结果

- 完整测试套件：**2723 passed, 3 skipped, 0 failed**（修复前 21 failed）。
- 环境侧同时补齐：安装 `agent-sandbox` 可选依赖、启动 Docker daemon、
  拉取并验证沙箱镜像。

## 后续

- 沙箱镜像约 13 GB，CI 中不宜每次拉取，可考虑构建缓存或使用更小的替代镜像。
- `agent_sandbox` 缺席时的占位注入仍是模块级 `sys.modules` 写入，虽已加
  "真实包优先" 保护，仍建议后续统一为 fixture 方案。
